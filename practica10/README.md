# Práctica 10 – Uso de Cámara

Aplicación Android con Jetpack Compose que solicita permiso de cámara en tiempo de ejecución y captura fotografías con `ActivityResultContracts.TakePicturePreview`. Las fotos se muestran en una cuadrícula.

## Características

- Permiso `CAMERA` en el manifiesto.
- Solicitud explícita de permiso con `RequestPermission`.
- Captura con `TakePicturePreview`.
- Renderizado del `Bitmap` capturado.
- `LazyVerticalGrid` para las fotos.

## Ejecución

1. Abrir el proyecto en Android Studio.
2. Sincronizar Gradle.
3. Ejecutar en un dispositivo o emulador con cámara.
