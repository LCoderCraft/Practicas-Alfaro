# Práctica 09 – Galería de Imágenes

Aplicación Android con Jetpack Compose que muestra una galería de imágenes en una cuadrícula adaptativa. Las imágenes se cargan de forma asíncrona con Coil y al tocar una imagen se abre una vista ampliada en un diálogo.

## Características

- `LazyVerticalGrid` con columnas adaptativas.
- `AsyncImage` de Coil.
- Placeholder y manejo de error en la carga.
- Vista detallada con `Dialog`.
- Permiso de Internet en el manifiesto.

## Ejecución

1. Abrir el proyecto en Android Studio.
2. Sincronizar Gradle.
3. Ejecutar en un emulador o dispositivo con Internet.
